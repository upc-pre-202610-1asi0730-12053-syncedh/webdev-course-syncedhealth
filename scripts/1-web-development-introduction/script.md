# Script Video 1: Introduccion al desarrollo web

Bienvenidos a este curso de Fundamentos de Desarrollo Web con HTML y CSS. En este curso aprenderemos, desde cero, como se crean las paginas web que vemos en internet.

En esta primera leccion vamos a conocer que es el desarrollo web y como se crean las paginas que usamos todos los dias en internet.

No necesitas instalar nada. Solo vamos a usar herramientas online desde el navegador.

Cuando abrimos una pagina como una red social, una tienda online o una pagina de noticias, estamos usando un sitio web.

Un sitio web es un conjunto de paginas que podemos ver desde un navegador, como Chrome, Edge, Firefox o Safari.

Todo el contenido no aparece por magia. Detras hay codigo que le dice al navegador que debe mostrar.

Una pagina web puede tener varias partes.

Puede tener un titulo para indicar de que trata, textos para explicar informacion, imagenes para hacerla mas visual, botones para realizar acciones y enlaces para ir a otras paginas.

La pregunta es: como le decimos al navegador que muestre todo eso?

Ahi entran dos tecnologias muy importantes: HTML y CSS.

Podemos imaginar una pagina web como una casa.

HTML seria la estructura de la casa. Es decir, las paredes, las puertas, las ventanas y las habitaciones.

En una pagina web, HTML nos ayuda a colocar los elementos principales, como titulos, parrafos, imagenes, listas, enlaces y botones.

CSS seria la decoracion de la casa. Sirve para cambiar colores, tamanos, tipos de letra, bordes, espacios y la posicion de los elementos.

Entonces, de forma sencilla, HTML responde a la pregunta: que elementos tiene mi pagina?

Y CSS responde a la pregunta: como se ven esos elementos?

Por ejemplo, HTML puede crear un titulo, pero CSS puede hacer que ese titulo sea azul, grande y centrado.

Para practicar desarrollo web no vamos a instalar ningun programa.

Vamos a usar CodePen, que es un editor online. Eso significa que podemos escribir codigo directamente desde el navegador y ver el resultado al instante.

En CodePen normalmente tenemos una zona para HTML, una zona para CSS y una zona donde aparece el resultado.

En la parte de HTML escribimos los elementos de la pagina.

En la parte de CSS escribimos como queremos que se vea.

Y en la parte de resultado vemos la pagina funcionando.

Como ejemplo rapido, si escribimos un titulo y un parrafo en HTML, el navegador ya puede mostrar ese contenido en pantalla.

No vamos a profundizar todavia en cada etiqueta, porque eso lo veremos en la siguiente parte.

Puedes pausar el video por un momento y observar CodePen.

Fijate que hay un espacio para escribir HTML, otro para CSS y una zona donde aparece el resultado.

Esa sera nuestra herramienta principal para practicar.

En esta primera parte aprendimos que un sitio web es un conjunto de paginas que vemos desde un navegador.

Tambien vimos que HTML sirve para crear la estructura de una pagina, mientras que CSS sirve para darle estilo visual.
