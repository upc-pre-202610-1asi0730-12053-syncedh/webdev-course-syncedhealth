(1:00 - 2:45) Cómo subir y compartir tu Web en Replit

Ahora queremos que todo el mundo vea tu creación. Para eso usaremos Replit, una herramienta en línea 100% gratuita que te permite alojar tu página en internet.
Lo único que debes hacer es copiar el código HTML y CSS que creaste en CodePen y pegarlo en un nuevo proyecto en Replit. Al hacer clic en el botón 'Run' o 'Ejecutar', Replit te dará un enlace único. ¡Copia ese link! Ya puedes enviárselo a tus amigos o familiares por mensaje para que lo abran desde sus celulares o computadoras.

(2:45 - 3:45) Consejos para seguir aprendiendo

¡Este es solo el comienzo! El desarrollo web es un mundo gigante. Si te gustó crear esto, te recomiendo investigar sobre JavaScript, que es el lenguaje que le da superpoderes y animaciones avanzadas a las páginas web.

También puedes explorar sitios gratuitos como MDN Web Docs de Mozilla o W3Schools, donde encontrarás miles de trucos visuales y nuevas propiedades de CSS para seguir experimentando a tu propio ritmo.
