**Introducción y analogía**
<br>
¡Hola! Bienvenidos a este nuevo video. En las lecciones anteriores aprendimos a usar HTML para crear el esqueleto y los textos de nuestra página web. Pero seamos honestos... se ve un poco aburrida, ¿verdad? Todo en blanco y negro. Hoy vamos a cambiar eso gracias a CSS.
<br>
Si HTML es el esqueleto de una casa, CSS es la pintura, la decoración y los muebles que la hacen lucir increíble. CSS significa Hojas de Estilo en Cascada, y es el lenguaje que le dice al navegador exactamente cómo queremos que se vea nuestro contenido.
<br><br>
**Cómo se conecta en editores en línea**
<br>
Una gran ventaja de usar editores en línea como CodePen es que conectar HTML con CSS es automático. Si miras la pantalla, tenemos una caja para escribir nuestro HTML y, justo al lado o abajo, una caja exclusiva para CSS. Lo que escribamos en la caja de CSS cambiará mágicamente el diseño del HTML que está al lado.
<br><br>
**Explicación de los selectores (Manos a la obra)**
<br>
Para cambiar algo, primero debemos 'seleccionarlo'. La estructura básica en CSS es muy sencilla: escribimos el nombre de la etiqueta que queremos cambiar (por ejemplo, h1 o p), abrimos llaves { }, ponemos la propiedad que queremos modificar, dos puntos, y el valor. ¡Ah! Y nunca olvides cerrar con un punto y coma ;.
<br>
Vamos a escribir este código juntos en nuestras pantallas.
