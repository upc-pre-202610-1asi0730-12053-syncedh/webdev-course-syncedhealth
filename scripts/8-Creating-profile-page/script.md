# Video 8: Creación de una página de perfil

### 1. Introducción y presentación del proyecto
* **Visual:** Muestra la hermosa tarjeta de perfil terminada con la cara de Steve de Minecraft, textos verdes y botones amarillos. Luego limpia el HTML para empezar de cero.
* **Audio:** "¡Hola, gamers! Bienvenidos a la lección práctica final. Hoy uniremos todo el HTML y CSS aprendido para construir desde cero una tarjeta de perfil gamer totalmente personalizada y centrada en nuestro navegador web."

### 2. Estructurando el HTML
* **Visual:** Escribe dentro de la pestaña HTML las etiquetas `<main>`, `<img>` (con el enlace de la cara de Steve), `<h1>` y la lista `<ul>` con sus tres `<li>`.
* **Audio:** "En la pestaña HTML, abrimos nuestra caja contenedora `<main>`. Adentro, insertamos la imagen del avatar con `<img>`. Colocamos nuestro nombre de usuario en un `<h1>`, y creamos una lista desordenada `<ul>` con tres elementos `<li>` para nuestros videojuegos favoritos. Ya están los textos, ahora démosle estilo."

### 3. Aplicando el diseño y el truco de la foto redonda
* **Visual:** Pasa a CSS. Escribe las propiedades del bloque `main`. Luego va a `img`, cambia el tamaño a `100px` y le agrega `border-radius: 50%;` junto con el borde `darkgreen`.
* **Audio:** "En CSS, seleccionamos `<main>`. Ponemos un fondo gris claro, ancho de `320px`, un padding de `30px` y `text-align: center;` para alinear todo en el medio. ¡Ya tomó forma! Ahora un truco con la imagen `img`: ajustamos su tamaño a `100px` y escribimos `border-radius: 50%;`. ¡Listo! Nuestra foto de Steve ahora es un círculo perfecto."

### 4. Estilizando los videojuegos como botones
* **Visual:** Escribe los bloques para `ul` (quitando el estilo de lista) y para `li` aplicando el color de fondo amarillo, el margen y el padding.
* **Audio:** "Para el toque final, seleccionamos `ul` y escribimos `list-style: none;` para borrar esos puntos negros aburridos. A cada elemento `<li>` le ponemos un fondo amarillo, un espacio interno con `padding: 8px;` y esquinas redondeadas. ¡Se ven fantásticos, parecen botones reales de un menú de videojuegos!"

### 5. Pausa para el Proyecto Final
* **Visual:** Aparece el cartel en pantalla: *¡Llegó el Proyecto Final! Pausa y personaliza*.
* **Audio:** "(Consejo en pantalla: ¡Llegó el momento de tu Proyecto Final!) ¡Es tu turno! Abre el enlace base de CodePen en la descripción, ponle pausa al video y edita la tarjeta con tu propio nombre, tu foto favorita y tus tres juegos preferidos. ¡Sorpréndenos con tu diseño!"

### 6. Cierre
* **Visual:** Muestra brevemente la tarjeta personalizada y se despide.
* **Audio:** "¡Muchas felicidades! Has creado tu primera página web real uniendo HTML y CSS con total éxito. En la próxima lección, Sebastián te enseñará los errores más comunes que debes evitar para que tu código sea impecable. ¡Gracias por acompañarme y a seguir programando!"
